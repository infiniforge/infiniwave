# InfiniWave silent audio fixtures

InfiniWave-silent-inputs.zip contains three valid five-second PCM WAV files for
exercising import, resampling, channel lanes, project save/open and WAV export:

- silence-44100-mono.wav: 44.1 kHz, mono, 16-bit PCM
- silence-48000-stereo.wav: 48 kHz, stereo, 16-bit PCM
- silence-22050-mono.wav: 22.05 kHz, mono, 16-bit PCM

All sample frames are zero. InfiniFolder can browse the archive; with Android
SAF, extract it and select one of the WAV files.
